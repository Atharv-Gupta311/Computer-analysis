# Computer-analysis
Windows log dump and analysis of the health of the machine.

## Overview

This project collects Windows diagnostic information and performs an initial health analysis.

## Repository Structure

```
logs/     - Windows event logs
dumps/    - Crash dump files
report/   - Machine health reports
src/      - Analysis code
```

## Current Progress

- Collected Windows Application logs
- Collected Windows System logs
- Collected crash dump
- Initial health report created

## Next Steps

- Parse Windows event logs
- Classify errors by severity
